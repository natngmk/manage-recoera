# Customer reply

1. **Understand the request.** Identify the issue (order status, return, refund, sizing, damage,
   complaint) and what the customer wants.
2. **Look up facts** (order status, tracking, product details) with the store connector if available.
   Otherwise ask the user. Never guess order status or promise timelines you can't verify.
3. **Read `docs/brand-voice.md`** for tone and sign-off.
4. **Draft the reply:** acknowledge the issue, give a clear answer or next step, and keep it short.
5. **Flag anything that needs a decision** (refund amount, replacement, exception to policy) for the user
   instead of deciding it.
6. **Show the draft only.** Never send messages or issue refunds without explicit confirmation.
