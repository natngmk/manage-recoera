# Product listing

1. **Gather facts.** Get the product details from the store connector if one is configured, or from what the
   user provides (name, materials, sizes, price, photos, target customer). Ask for anything missing that
   matters. Never invent specs.
2. **Read `docs/brand-voice.md`** and follow its tone and formatting rules.
3. **Draft:**
   - Title (follow the title format in brand voice)
   - Short description / hook (1–2 sentences)
   - 3–5 benefit bullets
   - Specs / sizing / care
   - SEO title (≤ 60 chars), meta description (≤ 155 chars), 5–10 tags
4. **Show the draft** to the user. If updating an existing listing, show old → new side by side.
5. **Confirm before writing.** Only push to the live store after an explicit yes. Otherwise save to
   `data/listings/<product-slug>.md`.
